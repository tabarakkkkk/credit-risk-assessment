# Previous Default Policy

## Section 1 — Prior default
A previous default is a risk factor that requires closer review. The review should consider how recent it was, whether the balance was resolved, and whether later payments were consistent.

## Section 2 — Resolved default
A resolved default does not automatically determine an outcome in this educational policy. The assistant should explain the factor and request current evidence rather than make an approval or rejection decision.
